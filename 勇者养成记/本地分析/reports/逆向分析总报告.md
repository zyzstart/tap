## 3. 技术结构与启动链

### 3.1 Android 是 SDK/渠道桥，主要玩法在 IL2CPP

Launcher 为 `DodUnityPlayerActivity`，直接继承 `android.app.Activity`，内部创建 `UnityPlayer`，不能仅凭名字写成继承 `UnityPlayerActivity`。应用包含 DOD 平台桥、腾讯 YSDK、Midas 支付及 Bugly 等组件；已找到实际 Java 初始化和充值桥调用，而不是只根据文件名判断。

Manifest 中 `DOD_PLATFORM_NAME=hardtime`、`ChannelId=550`，结合配置加载桥，静态候选链为：

`Manifest → DodLibConfig.Init / PlatformConfig → GetConfigBytesConfig("Config_%s.bytes") → hardtime 配置`

对应 [渠道配置原文](<../unpacked/assets/Config_hardtime.bytes>) 为 version `2.10`，包含 HTTP 主机 `web.ysr.hardtime.cn`。这只是静态选择候选，不是当前线上入口或完整网络拓扑的证明。默认配置中的 `192.168.1.2` 属于 dev 配置，**不能认定为正式游戏服务器**。更多渠道与桥调用证据见 [Android 层分析](<Android层分析.md>)。

### 3.2 Unity 与双架构 IL2CPP

两套架构均从主 IL2CPP 原生库配合主 metadata 成功恢复声明。每套识别 9,560 class、442 struct、858 enum、422 interface；另将泛型实例化注释块独立索引，避免混入类型/方法统计。

- [ARM64 声明](<../derived/il2cpp/arm64-v8a/dump.cs>)、[ARMv7 声明](<../derived/il2cpp/armeabi-v7a/dump.cs>)。
- [索引说明](<../derived/il2cpp/index/README.md>) 提供程序集提取、类型与成员 JSONL、原始行号和地址。
- [索引校验](<../derived/il2cpp/index/verification.json>) 对声明、成员、原始行、跨 ABI 类型/签名及导出链接做静态一致性检查。

ARM64 注册地址为 CodeRegistration `0x2c68e28`、MetadataRegistration `0x2c68e98`；ARMv7 分别为 `0x2289348`、`0x2289380`，见 [ARM64 日志](<../logs/il2cpp-arm64.log>)、[ARMv7 日志](<../logs/il2cpp-armv7.log>)。地址用于对应版本/架构的静态定位，不是运行时绝对地址。

**证据分层：** Dumper 方法体仍为空壳，不能据其名称声称恢复实现。本轮另外直接反汇编 ARM64 原生库，恢复了 FP/随机/属性与若干伤害数值阶段；这些结论的证据在[算法报告](<客户端玩法算法还原.md>)，不是来自空壳源码。未将配置权重当实际掉率，也未声称 ARMv7 算法等价；跨 ABI 声明一致不等于机器码行为相同。

### 3.3 资源与配置组织

Bundle 包含模型、动画、贴图、UI、特效、场景、文本配置等。对象规模包括：8,675 Texture2D、9,228 Sprite、200 SpriteAtlas、2,734 Mesh、4,169 AnimationClip、1,374 AnimatorController、428 AudioClip、70,254 MonoBehaviour。

所有 Bundle 可解析，但本轮仅导出 TextAsset、特定配置/场景 typetree 和少量预览，**没有进行模型、音频、动画全量转换**。具体对象可从 [对象清单](<../derived/unity/object-index.csv>) 按 bundle、类型、path ID、container path 查询。

## 5. 异常与失败保留

1. **全量 JADX 部分失败。** 返回码 3；保留 3,567 个 Java 文件、15 个 `Method not decompiled` 占位和一条严重反编译错误定位。14 个单独选择的关键类均返回 0。详见 [完整状态](<../derived/android/jadx_full_status.json>)、[问题定位 CSV](<../derived/android/java_decompilation_issues.csv>)。不能用外层 Python 退出 0 抹掉内部工具失败。
2. **ABI 目录/ELF 类型异常。** ARM64 目录中的 [libdodjoy.so](<../unpacked/lib/arm64-v8a/libdodjoy.so>) 与 [libxlua.so](<../unpacked/lib/arm64-v8a/libxlua.so>) 实际为 ARM32 ELF。仅记录打包异常，未证明会被装载、运行崩溃或可利用。
3. **额外 DEX 不等于已解密代码。** [非标准 DEX 样本](<../unpacked/assets/39285EFA.dex>) 仅 71,500 字节、头部非标准；本轮未证明其为有效第二 DEX或已恢复其内容。
4. **XLua 不等于找到 Lua 玩法。** 原生符号能证明库的存在，不能证明主流程调用；未交付可读 Lua 玩法源码。
5. **签名未认证。** 提取了 V1 证书容器及摘要，未验证 APK 全部签名、证书可信度或签名者身份；也未据此认定“官方正版”。
6. **Manifest 风险只是静态候选。** HTTP、旧 targetSdk、导出组件等没有经过设备或服务端利用验证；无证据的“文件泄露”“支付绕过”等结论未写入。

复跑入口及宿主环境要求见 [复现与工具说明](<复现与工具说明.md>)。本轮结论不包含动态验证或游戏可独立运行保证。
