# 复现步骤、工具与完整性说明

## 1. 安全约定与输入

- 原始输入：[APK](<../../com.tencent.tmgp.yzycj_227.apk>)。不要改名、覆盖、重签名或把派生产物写回 APK。
- 样本只作为 ZIP、AXML、DEX、ELF、metadata、AssetBundle 和二进制配置读取；**不安装、不启动、不调用游戏原生函数、不登录或访问游戏服务器**。
- 输出统一位于 [本地分析归档](<../>)。参考其他项目的目录组织不意味着可以直接导入其脚本；本归档的入口脚本均独立保存。
- 复跑会覆盖同阶段派生分析和报告。若要保留人工编辑，请先复制相应报告，不要对源 APK 做实验。

## 3. 最短复核路线

在项目目录 `D:\VibeCoding\勇者养成记` 打开 PowerShell 7：

```powershell
$ErrorActionPreference = 'Stop'
$env:PYTHONUTF8 = '1'
$env:PYTHONDONTWRITEBYTECODE = '1'
$py = 'C:\Users\Admin\.dsh\dsh-runtimes\dsh-primary-runtime\dependencies\python\python.exe'

# 不重新反编译/导出，只检查输出与原始输入，更新校验快照。
& '.\本地分析\tools\run_analysis.ps1' -Stage Validate -Python $py
& '.\本地分析\tools\run_analysis.ps1' -Stage Verify -Python $py
```

[包装入口](<../tools/run_analysis.ps1>) 默认执行 `Verify`。它不自动跑全部阶段，不静默下载缺失工具，也不启动 APK。包装器遇到原生命令非零退出即抛错；Android 内部反编译的部分失败则还要读取结构化状态。

## 4. 从现有 APK 全量复跑的顺序

```powershell
# 沿用上一节 $py、UTF-8 和 Stop 设置。
& '.\本地分析\tools\run_analysis.ps1' -Stage SelfTest -Python $py
& '.\本地分析\tools\run_analysis.ps1' -Stage Extract -Python $py
& '.\本地分析\tools\run_analysis.ps1' -Stage Android -Python $py
& '.\本地分析\tools\run_analysis.ps1' -Stage Native -Python $py
& '.\本地分析\tools\run_analysis.ps1' -Stage Unity -Python $py

# dotnet 应在 PATH；两次必须传不同 ABI。
& '.\本地分析\tools\run_analysis.ps1' -Stage Dump -Abi arm64-v8a -Python $py
& '.\本地分析\tools\run_analysis.ps1' -Stage Dump -Abi armeabi-v7a -Python $py
& '.\本地分析\tools\run_analysis.ps1' -Stage Index -Python $py
& '.\本地分析\tools\run_analysis.ps1' -Stage ParserCalls -Python $py
& '.\本地分析\tools\run_analysis.ps1' -Stage ResBin -Python $py
& '.\本地分析\tools\run_analysis.ps1' -Stage ResBinExtended -Python $py
& '.\本地分析\tools\run_analysis.ps1' -Stage Variants -Python $py
& '.\本地分析\tools\run_analysis.ps1' -Stage RecursiveVariants -Python $py
& '.\本地分析\tools\run_analysis.ps1' -Stage Catalog -Python $py
& '.\本地分析\tools\run_analysis.ps1' -Stage Algorithms -Python $py
& '.\本地分析\tools\run_analysis.ps1' -Stage Validate -Python $py
& '.\本地分析\tools\run_analysis.ps1' -Stage Verify -Python $py
```

主要阶段说明：

| Stage | 入口 / 行为 | 注意事项 |
|---|---|---|
| SelfTest | [解包测试](<../tools/test_extractor.py>) | 5 个小型合成样例，不操作真实 APK |
| Extract | [安全解包](<../tools/extract_apk.py>) | 相同文件可续跑；冲突拒绝覆盖；检查原始 ZIP 名称、遍历、绝对路径、反斜杠及大小写冲突 |
| Android | [Android 分析](<../tools/analyze_android.py>) | 无参 full 会重算结构并复用已有 JADX 状态；不是默认重跑全量 JADX |
| Native | [原生清单](<../tools/analyze_native.py>) | 读取 40 个 ELF、metadata 和字符串；不执行 SO |
| Unity | [Unity 导出](<../tools/analyze_unity.py>) | 默认全部 3,942 Bundle；直接调用脚本的 `--limit` 仅用于试跑，不可当全量结果 |
| Dump | [Dumper 工具](<../tools/il2cppdumper/>) | 主 metadata + 同 ABI 主 IL2CPP；不把热更 SO 随意配给主 metadata |
| Index | [声明索引](<../tools/index_il2cpp.py>) | 标准库解析，含原始行、程序集边界、跨 ABI 和链接校验 |
| ParserCalls | [直接调用清单](<../tools/inspect_unpack_calls.py>) | 辅助证据清单，不代替 ResBin 的字段偏移/局部 CFG 检查 |
| ResBin | [保守解码](<../tools/decode_resbin.py>) | 不支持的表保留原字节；具体假设见 [配置说明](<资源与配置解码.md>) |
| ResBinExtended | [原生递归解码](<../tools/decode_resbin_extended.py>) | 174 个基线数组/嵌套拒绝项；固定数组/子结构读取门禁，不改基线 |
| Variants | [平面伴生候选](<../tools/recover_wire_layouts.py>) | 15 份候选；未知尾字段保留，不晋升原生证据表 |
| RecursiveVariants | [递归伴生候选](<../tools/recover_recursive_variants.py>) | 8 份候选；所有具名叶值严格一致或位精确 float32 投影 |
| Catalog | [目录与手册生成](<../tools/build_gameplay_catalog.py>) | 合并 545 个源身份，按证据层级查询；不重复改写旧解码输出 |
| Algorithms | [算法证据与模型](<../tools/recover_client_algorithms.py>) | 反汇编/调用边/读取分发表/宿主参考模型与测试，不加载执行游戏 SO |
| GameplayValidate | [玩法验证](<../tools/validate_gameplay_outputs.py>) | 重新从 SO 分析 223 个 schema；扩展/候选回编码、CSV 与唯一来源身份；重解 115 入口/10,460 指令及 30 个跳表项；54 项单元测试、生成器与交付模型各 62 项宿主检查 |
| Validate | [全量输出验证](<../tools/validate_outputs.py>) | 包含 GameplayValidate，再检基线回编码、TextAsset 哈希、Python AST、报告本地链接 |
| Verify | [完整性快照](<../tools/verify_archive.py>) | 原 APK/全部解包文件对照初始哈希；派生文件及支持文件生成当前快照 |

对于耗时命令，建议明确保存 UTF-8 日志并检查退出状态，例如：

```powershell
& '.\本地分析\tools\run_analysis.ps1' -Stage Unity -Python $py 2>&1 |
    Out-File '.\本地分析\logs\unity-export.log' -Encoding utf8
# 上层 ErrorActionPreference=Stop；脚本内部也检查原生命令退出码。
```

避免用默认重定向生成难读的 UTF-16 日志后误当 UTF-8。过程日志位于 [日志目录](<../logs/>)。

若只复核新增玩法内容，可运行：

```powershell
& '.\本地分析\tools\run_analysis.ps1' -Stage GameplayValidate -Python $py
# 仅重跑算法生成器的宿主参考测试（不代替上面交付模型/原生证据复核）：
& $py -B '.\本地分析\tools\recover_client_algorithms.py' --test-only
```

玩法验证器已用 `unittest.TextTestRunner(stream=sys.stdout)` 输出回归结果。直接运行默认向 stderr 写日志的 unittest 再经 PowerShell `2>&1 | Tee-Object`，可能出现 `NativeCommandError`；请同时读真实退出码和测试结果，不把 stderr 输出本身认作测试失败。

**按当前索引而不是 glob 全目录读表。** 扩展输出曾因同名 fp/nonfp 来源共用路径发生覆盖，现已预分配来源身份路径并验证完整 `doc.source == index entry`。旧路径的 24 个 JSON/CSV 仅作为 `UNINDEXED-stale` 历史证据留存，绝不计入 164 张有效递归表；[输出审计](<../derived/config-extended/output-validation.json>)有逐文件相对/绝对路径、哈希和 `current_deliverable:false`。

## 5. 显式重跑 JADX 与失败含义

```powershell
& $py '.\本地分析\tools\analyze_android.py' --phase full --jadx --jadx-full `
    --java 'D:\Android Studio\jbr\bin\java.exe'
```

- `--jadx` 补做缺失关键类；成功缓存可复用。
- `--jadx-full` 明确重新跑完整主 DEX；采用 `-Xmx2G -j3 --no-res` 等参数，不反编译 Android 资源包以节省空间。
- 当前全量 JADX 退出码 **3**、3,567 个 Java 文件、15 个未恢复方法，占位与错误日志原样保留。外层分析脚本可正常结束并生成“部分失败”报告，**因此外层退出码 0 不代表 JADX 全量成功**。

必须同时检查 [JADX 全量状态](<../derived/android/jadx_full_status.json>)、[失败定位](<../derived/android/java_decompilation_issues.csv>)、[原始日志](<../derived/android/jadx_full.log>)、[Android 执行摘要](<../derived/android/run_summary.json>)，不要盲目反复重跑同一个失败任务。

## 6. 校验清单如何读

- [源 APK 哈希](<../inventory/source.sha256>)、[APK 原始清单](<../inventory/apk-files.csv>)：解包时的基线。
- [最终完整性结果](<../inventory/verification.json>)：原 APK 是否未变、解包哈希失败数、当前派生/支持文件规模。
- [派生文件清单](<../inventory/derived-files.csv>)：所有派生产物当前大小/SHA-256。
- [支持文件清单](<../inventory/support-files.csv>)：工具、Python 依赖、报告、README 和主要 inventory 当前哈希，排除日志、`__pycache__` 和自引用清单。
- [全量输出验证](<../inventory/output-validation.json>) / [玩法扩展验证](<../inventory/gameplay-validation.json>)：444 份原生布局支持源表与 23 份候选分开计数，结构/转换与宿主模型测试；不执行游戏。
- [算法测试向量与结果](<../derived/client-algorithms/test-results.json>)：含 4,096 组乘法、4,096 组除法独立算术比较、多块 MT19937 标准库 oracle、手算伤害阶段向量；不代表原生差分执行。
- [解包安全测试结果](<../logs/extraction-selftest.json>)：正常续跑、冲突拒绝、目录穿越、大小写冲突、反斜杠五项。

派生和支持文件清单是**当前快照**，不是数字签名或独立可信时间戳；再次执行 Verify 会重新生成。若要长期防篡改，另行离线保留这批清单的外部哈希或只读副本。后续修改/再导出后应先 Validate 再 Verify，避免拿旧快照描述新文件。

## 7. 关于容量与后续分析

归档保留原始解包、双 ABI 声明、JADX 部分输出、索引、工具和依赖，没有重复复制整个 APK，也没有全量展开所有美术为大尺寸图片或模型。已有来源链足够按需导出；不要为了“逆向完整”盲目增加数 GB 无导航文件。

本轮没有动态运行环境或可玩还原项目。若继续，建议一次明确一个具体方法、表格式或美术类别，并将新增结果沿同样的输入哈希、地址/对象 ID、输出哈希与限制归档。
